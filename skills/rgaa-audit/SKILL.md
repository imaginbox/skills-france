# Skill RGAA Audit

Audit d'accessibilite RGAA v4.1.2 (WCAG 2.1 AA) pour sites web francais.

## Quand utiliser
- Quand l'utilisateur demande un audit d'accessibilite
- Quand on developpe un site public francais (obligation legale)
- Avant une mise en ligne (conformite RGAA)

## Methode
1. Analyser le code HTML/CSS/JS du site
2. Verifier les criteres RGAA (voir criteres.md)
3. Generer un rapport avec les non-conformites
4. Proposer des corrections

## Criteres RGAA (extraits)
Voir criteres.md pour la liste complete des 81 criteres.

## Sortie
- rapport-rgaa.md : liste des non-conformites + severite + correction
- score : 0-100 (taux de conformite)
