# Skill Legal-FR

Reference juridique francaise : codes, contrats, jurisprudence.

## Quand utiliser
- Quand l'utilisateur a une question de droit francais (contrat, travail, civil, commercial)
- Pour rediger ou verifier un document juridique simple
- Pour identifier les articles applicables a une situation

## Methode
1. Qualifier la situation (droit civil / travail / commercial / consommation)
2. Identifier le texte applicable (voir sources.md)
3. Citer les articles precis (numero + libelle)
4. Si pertinent, mentionner la jurisprudence de reference
5. **Toujours** ajouter l'avertissement : ceci est une information generale,
   pas un conseil juridique - consulter un avocat pour une situation concrete

## Sources officielles
Voir sources.md : Legifrance, INPI, DILA, base de jurisprudence.

## Redaction de contrats
- Utiliser les templates de templates/ (bail, CDI, CDD, prestation, cession)
- Verifier les clauses obligatoires du Code civil (art. 1128 et s.)
- Signale les clauses abusives (Code de la consommation, art. L212-1 et s.)

## Limites
- Pas de conseil juridique personnalisable
- Le droit change : verifier la date de mise a jour des textes sur Legifrance
- Pour les litiges : orientation vers un professionnel (avocat, notaire, mediator)

## Sortie
- Articles cites avec leur libelle
- Resume de la regle applicable
- Avertissement legal en fin de reponse
